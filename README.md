# 🛡️ SafeZone – Campus Safety Intelligence Platform

A cross-platform safety application built using Flutter and Firebase to enable real-time incident reporting, secure authentication, and campus-wide safety awareness.

---

## 📌 Executive Summary

SafeZone is a scalable, real-time safety reporting platform designed for academic institutions.  
It centralizes incident reporting and alert broadcasting to improve response time and visibility.

---

## 🎯 Problem Statement

Traditional campus safety systems rely on manual reporting methods, leading to:

- Delayed communication  
- Lack of centralized tracking  
- Limited real-time visibility  

SafeZone provides a secure and scalable digital safety ecosystem.

---

## 🚀 Core Features

- Real-Time Incident Reporting  
- Secure User Authentication (Firebase Auth)

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/gunasai12/Safe-Zone-Project-for-Academics.git
cd Safe-Zone-Project-for-Academics
```

### 2️⃣ Install Dependencies

```bash
flutter pub get
```

### 3️⃣ Configure Firebase

- Create a Firebase project  
- Register Android/iOS/Web apps  
- Download and replace configuration files  
- Update `firebase_options.dart` if required  

### 4️⃣ Run the Application

```bash
flutter run
```
